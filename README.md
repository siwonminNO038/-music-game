# 🎤 언더에서 그래미까지

음악으로 성공하는 인생 시뮬레이션 게임. 무명 뮤지션으로 시작해 곡을 쓰고, 앨범을 내고, 평단과 대중을 사로잡아 그래미 시상대까지 올라가 보세요.

## 실행 방법

빌드도 설치도 필요 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
진행 상황은 브라우저(localStorage)에 자동 저장되며, 메뉴에서 세이브 코드를 내보내거나 불러올 수 있습니다.

## 파일 구조

```
index.html       진입점
css/style.css    스타일
js/data.js       아티스트·레이블·크루·매체·시상식·반응 템플릿 데이터
js/text.js       제목 생성 재료, 평론/작업 노트 문장, 스토리 이벤트, 챕터, 투어
js/world.js      장르·스타일, 디스전·범죄 데이터와 문장
js/conflict.js   트렌드, 디스전, 범죄·재판, 세금, 개명·장르 전향 로직
js/expansion.js  장르·래퍼 추가, 해외 크루, 합작 앨범, 비트 판매, 팬덤, 해외 페스티벌
js/game.js       게임 로직 (DOM 의존 없음)
js/ui.js         화면 렌더링과 입력 처리
```

아티스트, 레이블, 크루는 실제 음악 씬을 모티브로 한 **가상의 패러디 캐릭터**입니다(예: 빈치노, AOMZ, 하이브리드 엔터, Kendall Lamarr). 실존 인물·단체와 관계가 없으며, 게임 속 사건은 모두 허구입니다. 무작위 범죄 뉴스는 패러디 캐릭터가 아닌, 게임이 생성한 신인들에게만 일어납니다.
