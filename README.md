# 🎤 언더에서 그래미까지

음악으로 성공하는 인생 시뮬레이션 게임. 무명 뮤지션으로 시작해 곡을 쓰고, 앨범을 내고, 평단과 대중을 사로잡아 그래미 시상대까지 올라가 보세요.

## 실행 방법

빌드도 설치도 필요 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
진행 상황은 브라우저(localStorage)에 자동 저장되며, 메뉴에서 세이브 코드를 내보내거나 불러올 수 있습니다.

## 주요 시스템

| 시스템 | 내용 |
| --- | --- |
| 🎼 작업물 | 곡 제목·장르·주제를 직접 정하고 프로듀서/피처링을 섭외해 작업. 싱글(1~3곡)·EP(3~7곡)·정규(8~25곡)로 발매하며, 트랙리스트 순서·타이틀곡·곡 제목·앨범 소개·커버 색/이모지를 직접 정함 |
| 📝 평단 | 리드머(★5, 힙합/R&B 전문, 짠 편), IZM(★5), 웨이브매거진(10점), Pitchfork(10.0, 해외 인지도 필요). 곡 완성도·앨범 응집력·평단 신뢰도로 점수와 리뷰 문장이 생성됨. 연말 결산 리스트도 발표 |
| 🏆 시상식 | 리드머 어워즈(1월) → 그래미(2월, 해외 인지도 20+) → 한국힙합어워즈(2월) → 한국대중음악상(3월) → 서울 스트리밍 어워즈(12월). 후보 발표 후 몇 주 뒤 시상식 진행 |
| 🤝 협업 | 국내·해외 가상 아티스트 50여 명 + 매년 새로 데뷔하는 신인. 친분 쌓기, 피처링/프로듀싱 섭외, 피처링 요청 수락, 컴필레이션 참여, 디스전 |
| 🏢 레이블·크루 | 인디부터 대형기획사, 미국 메이저까지 7개 레이블(계약금·수익 배분·홍보력·평단 신뢰도·연간 발매 의무가 다름). 기존 크루 합류 또는 크루 창설·멤버 영입·크루 컴필레이션 |
| 📱 SNS | 인스타그램/X/유튜브 게시물(일상, 작업 근황, 티저, 팬 소통, 저격, 사회적 발언, 뮤직비디오, 라이브 클립 등). 글 내용에 따라 반응이 달라짐 |
| 💬 팬 반응 | 찐팬·라이트팬·고인물·악플러·올드팬·해외팬·밈계정·타팬덤 페르소나가 발매·수상·논란·장르 변경·레이블 이적 등 상황별로 다른 댓글을 남김. 팬덤 여론과 팬 구성 비율 |
| 📊 차트 | 멜론 TOP 100(국내 스트리밍), 빌보드 HOT 100(글로벌 스트리밍), 빌보드 200(앨범 유닛). 골드/플래티넘/다이아몬드 인증, 역주행, 바이럴 |

그 밖에 멘탈·번아웃, 랩 서바이벌 출연, 광고, 스캔들, 디스전 등 랜덤 이벤트가 있습니다.

## 파일 구조

```
index.html       진입점
css/style.css    스타일
js/data.js       가상 아티스트·레이블·크루·매체·시상식·반응 템플릿 데이터
js/game.js       게임 로직 (DOM 의존 없음)
js/ui.js         화면 렌더링과 입력 처리
```

등장하는 아티스트, 레이블, 크루는 모두 가상입니다.
